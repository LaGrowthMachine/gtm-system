# Copywriting guidelines

## The principle

Outreach works when there is a reason to write to this person now. Every message starts from a signal or from a
tension the segment lives. The outline is written and approved first. Personalization rewrites each message from it, it does not
fix a weak outline.

## What changes when an agent writes per lead

Two ways to write a campaign, and only two:

- **A message per lead.** Each step of the campaign holds one custom attribute (`{{customAttributeN}}`) and nothing
  else. The attribute holds the whole message of that lead, written from the outline. The outline is a frame, not a
  text with blanks to fill.
- **The same message for everyone.** Each step holds the final text. `{{firstname}}` is the only variable.

Never a fixed text with a custom attribute in the middle of it. Every message has a fallback version, used when no
usable fact exists for a lead: a step never ships empty. The rules apply to the message as the lead reads it.

## House style, in every language

| Rule | Example |
|---|---|
| Never a comma before "and" or "or". The same in French before "et" and "ou". The serial comma included. | "LinkedIn and email", not "LinkedIn, and email". "Test it now or later", not "now, or later". |
| Never a long dash. | Use a comma or two sentences. |
| No colon to link two clauses inside a message. It reads as written by an AI. | "I can send you the agent. It is one skill to add to Claude.", not "I can send you the agent: one skill to add to Claude." |
| Positive words. We help the lead win something. | Not "miss", "lose" or "fall behind". |
| Never open with "Thanks for connecting". | Open on the question or on the fact. |

These rules also apply to any example of copy shown to the user, in any language.

## What our own campaigns add

Drawn from 71 campaigns across the three La Growth Machine workspaces. These complete the rule files.

| # | Do | Do not |
|---|---|---|
| 1 | Judge a campaign on positive replies. | Read a reply rate as interest: it can be made of thanks, out-of-office messages and resource requests. |
| 2 | Put the best message in the first touch. It carries most of the replies. | Save the strong argument for a follow-up. |
| 3 | Ask the question on LinkedIn. Use email to deliver, to remind or to answer a request. | Count on a cold email with a link to get a reply. |
| 4 | In a cold email, put a detail that belongs to the lead in the subject and in the body. | Send the same email to a whole list. |
| 5 | End on one question, closed or with two outcomes, about the lead's situation. | End on a link, "let's chat", "feel free" or "Can we connect?". |
| 6 | Make every follow-up bring something new for the lead. | Send one product feature per follow-up. |
| 7 | Give what the lead asks for, in the next message. | Answer a yes with another question. |
| 8 | Tie a customer you name to the lead's own case. | Name-drop a customer with no link to the lead. |
| 9 | Write in the lead's language. Keep the same register through the sequence. | Send the campaign's language to everyone. |
| 10 | Send one message as one block. | Split it into five bubbles in a minute. |

## Before writing for one lead

Four checks. They belong to targeting, they decide what the copy is worth.

1. The lead is not already a customer.
2. The lead is still in the role.
3. The lead is not already in another sequence.
4. The fact you use is true, public and recent.

If a premise about the lead is not checked (team size, activity), write it as a question.
